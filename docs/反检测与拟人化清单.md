# 上线前 · 反检测与拟人化清单

> **这是什么**:全自动方案能否存活的**命根子**(需求第 5 章 FR-9)。开发期为了快、为了验证逻辑,很多拟人化可以**先欠着**;但**真要拿号大量跑获客之前,这张清单必须逐项过一遍**。

>
> 状态:✅ 已做 ｜ ◐ 部分/基础版 ｜ ⬜ 待做(上线前补)

---

## 0 核心原则(先记牢)

不是"加几个拟人动作"就安全。风控("天枢",200+ 维度)看的是**综合行为指纹**:
**整体像不像真人 + 频率够不够低 + 账号够不够"养"**。
单加一个动作(比如"关闭再打开")而节奏照旧匀速,**换汤不换药,照样被识别**。三者要一起上。

---

## 1 浏览路径拟人化

- ⬜ **读详情改拟人路径**:从现在的"URL 直跳 `explore/{id}`"→ 改成"**搜索页点击卡片 → 详情弹层 → 阅读停留 → 关闭 → 回列表滚动 → 点下一张**"(2026-06-26 讨论;开发期先用 URL 直跳,快且稳)
- ⬜ **阅读停留时长随机**:有快有慢——有的笔记看很久,有的扫一眼就划走
- ⬜ **详情内滚动**:看正文、往下翻评论
- ⬜ **偶尔点赞/收藏**:低概率的真人互动
- ◐ **检索滚动拟人**:目前 `scrollBy` + 随机停顿(1.1~2.2s);待改:更不匀速、夹长停顿、偶尔回滚

## 2 限频与节奏 `FR-9.2/9.3/9.4`

- ⬜ 每类动作(采集 / 评论 / 私信)**各自独立的每日上限**
- ◐ 操作间随机延时(已有 `rand`;待优化:右偏分布、偶尔长停顿,别太均匀)
- ⬜ **配额浮动**(±随机)破坏规律性
- ⬜ **工作时间窗**:只在配置时段运行,可按周几区分
- ⬜ **养号阶梯**:新号 / 低权重号自动降速,逐步放量

## 3 输入 / 点击拟人化 `FR-9.1`

- ✅ **真实输入**:`Input.insertText`(`isTrusted=true`,非 JS 赋值)
- ◐ **鼠标点击**:已做 mousedown→dwell(60~150ms)→release 落点 ±1px 微抖;**待加贝塞尔曲线移动轨迹**(BOSS 有现成,可搬)
- ⬜ **打字逐字化** + 字间随机间隔(目前是一次性整段插入)
- ◐ **滚动用 trusted wheel**(`Input.dispatchMouseEvent` mouseWheel);目前检索用的是 JS `scrollBy`(`isTrusted=false`),待统一换

## 4 账号健康监控与刹车 `FR-9.5/9.6`

- ✅ **紧急刹车**:`tmp/STOP` 文件即停(基础版)
- ⬜ **检测限流/异常信号**:发送失败率、验证码、功能受限、提示异常
- ⬜ **异常自动降速 / 暂停** + 上报后台
- ⬜ **遇验证码 / 登录墙立即停**(别硬刚)

## 5 内容反刷屏 `FR-3.1`

- ◐ **评论不雷同**:开发期用模板;接 LLM 后 = 按笔记个性化生成 + 多条轮换 + 变量位
- ✅ **合规红线**:不发明文微信/电话/二维码/外链(`compliance.js`)
- ✅ **去重**:同一笔记不重复处理

## 6 设备 / 环境 / 账号隔离 `FR-9.1` / 需求 6 章

- ✅ **真实浏览器 + 真实指纹**:CDP 驱动用户真实 Chrome(非无头、非自动化浏览器)
- ⬜ **验证自动化特征是否暴露**:`navigator.webdriver` 等;必要时注入 stealth 脚本(BOSS 有)
- ⬜ **一账号 = 一浏览器 = 一机器**:防关联封禁
- ⬜ **住宅 IP**(别用机房 IP)

## 7 检索行为

- ⬜ 关键词 × 城市**分散执行**,别规律化批量扫
- ✅ 已采集去重,不重复触达
