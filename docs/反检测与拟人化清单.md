## 0 核心原则(先记牢)

不是"加几个拟人动作"就安全。风控("天枢",200+ 维度)看的是**综合行为指纹**:
**整体像不像真人 + 频率够不够低 + 账号够不够"养"**。
单加一个动作(比如"关闭再打开")而节奏照旧匀速,**换汤不换药,照样被识别**。三者要一起上。

## 1 浏览路径拟人化

- ✅ **读详情改拟人路径**:已从"URL 直跳 `explore/{id}`"改成"**搜索页点击卡片 → 详情弹层/详情页 → 阅读停留 → 关闭/Escape/后退兜底 → 回列表滚动 → 点下一张**";找不到列表卡片时跳过,不直跳详情。
- ⬜ **阅读停留时长随机**:有快有慢——有的笔记看很久,有的扫一眼就划走
- ⬜ **详情内滚动**:看正文、往下翻评论
- ⬜ **偶尔点赞/收藏**:低概率的真人互动
- ◐ **检索滚动拟人**:目前 `scrollBy` + 随机停顿(1.1~2.2s);待改:更不匀速、夹长停顿、偶尔回滚

## 2 限频与节奏 `FR-9.2/9.3/9.4`

## 3 输入 / 点击拟人化 `FR-9.1`

- ✅ **真实输入**:`Input.insertText`(`isTrusted=true`,非 JS 赋值)
- ✅ **鼠标点击**:贝塞尔曲线移动轨迹 + 落点抖动(不点正中心)+ mousedown→dwell(60~150ms)→release 微抖(BOSS 同款,已搬)
- ✅ **打字逐字化** + 字间随机间隔(45~140ms;已从"一次性整段插入"改为逐字)
- ✅ **滚动用 trusted wheel**(`Input.dispatchMouseEvent` mouseWheel,拆 280~500px tick + 横向漂移);已全换掉 JS `scrollBy`(`isTrusted=false` 的机器特征)
