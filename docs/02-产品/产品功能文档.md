## 1 产品总览

### 1.1 角色与使用场景

| 角色 | 用什么 | 典型场景 |
|---|---|---|
| 中介运营 | 桌面客户端（1 人 1 账号） | 配置城市/关键词/匹配/话术/房源 → 一键启动 → 机器自动获客 → 收到"转人工"提醒时接手 → 查看本账号线索 |
| 管理者 | 中央后台（网页） | 看所有账号今天跑得怎么样、有没有被限流、共产出多少线索；汇总导出线索 |

### 1.2 信息架构 / 页面地图

**桌面客户端**（左侧导航）：
- **控制台** — 启停总开关、今日数据、账号状态一览
- **检索** · **匹配规则** · **内容生成** — 获客策略三件套
- **房源素材库** · **话术库** — 素材两件套
- **触达执行** — 四类动作开关与节奏
- **线索** — 本账号线索列表 / 待接管对话
- **防封号与运行控制** — 限频、工作时间、养号、健康、紧急刹车
- **配置中心** · **运行日志** · **账号/接入设置**

**中央后台**（网页）：账号总览看板 · 线索汇总 · [P2] 租户管理

### 1.3 端到端使用流程

1. **接入** — 安装客户端 → 启动/连接已登录小红书的 Chrome → 绑定账号
2. **配置** — 设目标城市（可多城）+ 关键词 + 匹配条件 + 话术库 + 房源库 + 限频/工作时间
3. **启动** — 控制台一键启动；系统在限频与拟人节奏下自动运行
4. **自动获客** — 检索 → 分层匹配 → 生成话术+配图 → 评论/私信触达
5. **沟通转化** — 对方回复→自动多轮沟通、诱导加微；识别对方微信入库
6. **转人工** — 高意向/复杂对话→标记并提醒运营接手
7. **沉淀** — 线索本地保留 + 上报后台；管理者在后台统一观测

## 2.2 检索配置与执行 `[P0]`

> 样板模块：展示每个功能模块的统一写法（功能卡 + 验收标准 + 界面要点）。界面 mockup 见 HTML 版。

### 功能卡

| 字段 | 内容 |
|---|---|
| **功能目的** | 让运营自定义检索条件，系统据此在小红书上找到相关求租/房源笔记及其评论区，作为后续匹配与触达的来源。 |
| **用户怎么用** | 在"检索"页配置：目标城市（可多城、可开关）、搜索关键词、笔记类型、时间窗、采集范围 → 点"保存配置"；运行可由控制台总开关统一调度，也可在本页"开始检索"单独试跑。 |
| **详细规则** | ① 按"关键词 × 城市"组合生成检索词，逐个搜索；② 读取每条笔记：标题/正文/标签/发布时间/作者/地区，以及评论区（识别"问房子"的潜在客户）；③ 受全局限频与拟人节奏约束（翻页随机间隔）；④ 采集结果进入匹配漏斗（见 2.3）；⑤ 已处理的笔记/评论去重，不重复触达。 |
| **输入 / 输出** | 输入：检索配置。输出：候选笔记/评论列表（含元数据），写入本地待匹配队列。 |
| **异常与边界** | 搜索无结果→提示并跳过；页面改版/选择器失效→记录错误并告警（不静默失败）；触发限流→自动降速/暂停并上报；重复内容→去重跳过。 |
| **优先级** | P0 |
| **关联需求** | `FR-1.1~1.4` · `FR-C.1` · 需求 `4.2 L1` |

### 配置项

| 配置项 | 默认 | 取值/说明 |
|---|---|---|
| 地区匹配开关 | 开 | 关闭则不限城市 |
| 目标城市 | 空 | 可多城；**不绑账号属地**（人在 A 城业务在 B 城） |
| 搜索关键词 | 空 | 多个，逗号/换行分隔 |
| 笔记类型 | 求租+房源 | 求租帖 / 房源帖 可分别勾选 |
| 时间窗 | 无预设 | N 天内；求租按发帖、评论客户按评论时间 |
| 采集范围 | — | 每次最多 N 条、翻页深度 N 页 |

### 验收标准

- 配置 ≥2 个目标城市 + 多个关键词后，系统能按"关键词×城市"逐组检索并返回候选笔记。
- 关闭"地区匹配"后，检索不再受城市限制。
- 采集到的每条笔记都带：标题、正文、标签、发布时间、作者、地区、评论。
- 同一笔记/评论不会被重复采集进待处理队列。
- 翻页/采集间隔存在随机抖动，非固定节奏。
- 页面结构异常时有明确错误提示与日志，不静默丢数据。

### 界面要点（mockup 见 HTML 版）

- 左侧模块导航 + 主区"检索"页。
- "检索条件"卡片：地区匹配开关 → 目标城市标签（可加多个）→ 关键词多行输入 → 笔记类型勾选 → 时间窗输入 → 采集范围 → [开始检索] / [保存配置]。
- "本次运行"卡片：进度条 + 命中计数 + 候选笔记表（笔记/城市/发布/类型/状态）。
