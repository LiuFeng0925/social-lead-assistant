# 小红书自动化获客工具

面向租房中介的**小红书全自动获客系统**:自动检索笔记 → 分层匹配 → 自动评论/私信(带房源图文)→ 诱导加微/高意向转人工 → 线索沉淀。

形态:**每账号一个桌面客户端(Electron + CDP 驱动真实浏览器)+ 一个中央汇总后台**。

> ⚠️ 本工具涉及平台自动化,存在违反平台协议与账号封禁风险。以"真实浏览器 + 拟人节奏 + 严格限频"降低风险,仅供授权范围内使用。

## 关键决策速览

| 项 | 结论 |
|---|---|
| 自动化程度 | 全自动直发(限频/养号/刹车/健康监控为一等公民) |
| 客户端形态 | 桌面端 Electron + CDP 驱动真实浏览器,绕过 x-s 签名,不逆向 API |
| 架构 | 方案 A:客户端先行(本地 SQLite,可独立跑)+ 云端薄后台(Token 鉴权,多租户预留) |
| LLM | 国产可切换 provider(火山 Ark / 阿里百炼) |
| 触达动作 | 评论笔记 / 主动私信 / 自动回私信 / 回评论区(按风险排期) |
| 加微策略 | 诱导对方给微信为主 + 高意向转人工 |

> 完整决策见[需求文档](docs/01-需求/需求文档.html)第 12、13 节。本项目大量复用同机的 BOSS 直聘自动化项目(详见 CLAUDE.md)。
